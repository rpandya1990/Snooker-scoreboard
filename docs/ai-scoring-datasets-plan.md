# Recorded datasets implementation plan

**Basis:** [Approved extension](ai-scoring-datasets-design.md), [dataset requirements](ai-scoring-datasets-requirements.md). Recording storage remains local. No automatic training, remote inference or deployment.

**Implementation status:** Recording/lifecycle, immutable import/cohorts, alignment, blind review, configured local-adapter replay and replay evaluation are implemented. The installed companion suite passes 71 tests; independent QA passed the preceding 69-test suite and the final 19 affected recording/lifecycle tests. Real FFmpeg local-video recording/decoding and an import/replay workflow were exercised. Actual RTSP compatibility, production model inference and >90% held-out accuracy remain unverified. Setup: [Record your next game](record-your-next-game.md).

| Task / owner | Scope and dependencies | Acceptance checks |
| --- | --- | --- |
| Recording worker / SDE | Segmented FFmpeg capture, safe per-session asset paths, JSONL manifests, explicit budgets/retention, UTC/media anchors and uncertainty. Own recording modules and tests. | Off performs no capture. Finalised segments carry metadata/checksum. Missing/unfinished files and capture gaps are explicit. Storage limits stop recording without blocking scoring. Never delete active assets or persist source secrets. |
| Lifecycle integration / same SDE | Wire recording to companion session ownership, config and HTTP bootstrap. Depends on worker. | One worker per active lease, idempotent opens, stop/finish/shutdown finalise, periodic expiry works without requests. Fake-process and real synthetic local-file tests; no actual camera connection. |
| Dataset import/cohorts / independent SDE | New isolated dataset CLI/storage modules, importing validated assets/JSONL, immutable source provenance, cohort assignment. Agreed segment schema before implementation; no concurrent session/recorder edits. | Missing assets/checksum mismatch/traversal/symlinks rejected or explicitly incomplete. Source identity prevents duplicate footage crossing tuning/held-out cohorts. Assignment precedes outcomes. Live scoreboard and original JSONL stay untouched. |
| Offline replay / independent SDE | Adapter/version contract, time-limited footage decoding, inference input stripped of score answers, separate replay outputs. Depends on import and timeline contract. | Only footage through the original input cutoff enters a prediction. No user/reviewed scores or original totals in adapter input. Unknown alignment/missing adapter gives unavailable results. Tests use explicit fake adapters; no synthetic live accuracy claim. |
| Independent QA / QA | Validate stable installed package, prior regression tests, recording failure/lease paths, dataset/replay integrity and synthetic FFmpeg smoke. No production edits. | Report DS1–DS8 status and test evidence separately from real-camera/model feasibility. Route defects to SDE. |

Root owns integration, docs and final review. SDEs coordinate the segment manifest fields and final package installation; independent files may proceed in parallel. Existing Flutter behavior remains covered by its prior tests unless modified.

Before collecting actual future play, the operator sets camera credentials in protected service configuration, data directory, retention/storage/free-space limits and recording mode. Default recording stays off. Host capacity and real RTSP compatibility must be checked on the intended host. A visual adapter/model and held-out sample/confidence targets remain necessary for real scoring accuracy evaluation.
